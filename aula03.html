02 — Conceito

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem que define a aparência do HTML. Enquanto o HTML diz "o que existe", o CSS diz "como parece".

🎸 Analogia Pearl Jam

Pense no HTML como o palco e os instrumentos de um show do Pearl Jam: está tudo lá, estruturado. Mas o CSS é a iluminação, o figurino, o cenário e a mixagem de som. Sem CSS, o site existe — mas sem personalidade. Com CSS, o show tem alma.

1
HTML + CSS trabalham juntos
O HTML cria a estrutura (tags, conteúdo) e o CSS estiliza essa estrutura (cores, fontes, espaçamentos, layouts). Eles são arquivos separados mas se comunicam através do <link> no <head>.
2
Cascata — o que isso significa?
O "C" de CSS significa "Cascading" (cascata). As regras fluem em cascata: estilos do navegador → estilos do autor → estilos inline. Regras mais específicas ou mais tarde no arquivo sobrescrevem as anteriores.
3
Três formas de aplicar CSS
Inline — direto no atributo style="" da tag.
Interno — dentro de <style> no <head>.
Externo — arquivo .css separado, linkado com <link>. Esta é a forma profissional.
index.html — linkando o CSS externo
<!-- No <head> do seu HTML -->
<link rel="stylesheet" href="style.css" />

<!-- Assim o Pearl Jam conecta o style.css ao HTML -->
<!-- Tudo que estiver no style.css estiliza o HTML -->
💡 A página tributo do Pearl Jam usa arquivo CSS externo (style.css) — a forma mais organizada e profissional. Toda a aula de hoje vai explorar esse arquivo real!
03 — Sintaxe

Sintaxe do CSS

Toda regra CSS tem a mesma estrutura: um seletor que aponta o elemento, e um bloco de declarações com propriedades e valores.

.hero-title  {
color :  var(--cream-light) ;
font-size :  clamp(5rem, 15vw, 12rem) ;
}
▲ Seletor ▲ Propriedade ▲ Valor
style.css — anatomia de uma regra real do Pearl Jam
/* SELETOR → o que vou estilizar */
.nav-logo {
  /* PROPRIEDADE: VALOR; */
  font-family: 'Bebas Neue', sans-serif;
  font-size: 1.8rem;
  letter-spacing: 0.15em;
  color: var(--amber-bright);
  text-decoration: none;
}
Seletor
O "alvo" do estilo
Indica qual elemento será estilizado. Pode ser uma tag (nav), uma classe (.nav-logo), um ID (#hero), ou combinações.
Propriedade
O "aspecto" que muda
Define o que será alterado: color, font-size, background, display, padding, entre centenas de opções.
Valor
O "resultado" esperado
Define como será o aspecto: #1a0f07, 1.8rem, 'Bebas Neue', flex. Cada propriedade aceita tipos específicos de valores.
Comentário
Notas no código
Comentários em CSS ficam entre /* */. São ignorados pelo navegador mas essenciais para organizar o código. O Pearl Jam usa muito: /* ─── NAV ─── */.
04 — Seletores

Seletores e Especificidade

Seletores são o coração do CSS. Eles determinam quais elementos recebem um estilo. A especificidade determina qual regra ganha quando há conflito.

Tipo de Seletor Exemplo do Pearl Jam O que seleciona
tag nav, section, footer Todos os elementos com aquela tag HTML
.classe .hero-title, .album-card Todos os elementos com aquela classe
#id #hero, #discography O elemento único com aquele ID
pai filho .nav-links a Links dentro de .nav-links
elemento:estado .nav-links a:hover Estado especial (hover, focus, active)
elemento::pseudo .nav-links a::after Conteúdo virtual gerado por CSS

Especificidade — quem ganha?

Quando duas regras conflitam, o seletor com maior especificidade vence. Pense como pontos em uma competição:

tag (nav)
0-0-1
.classe
0-1-0
.classe tag
0-1-1
#id
1-0-0
style="" (inline)
1-0-0-0
style.css — pseudo-classes e pseudo-elementos do Pearl Jam
/* Pseudo-classe: estado hover */
.nav-links a:hover {
  color: var(--amber-bright);
}

/* Pseudo-elemento: linha animada embaixo do link */
.nav-links a::after {
  content: '';         /* conteúdo vazio mas necessário */
  position: absolute;
  bottom: -4px;
  width: 0;            /* começa invisível */
  height: 1px;
  background: var(--amber-bright);
  transition: width 0.3s; /* animação suave */
}

.nav-links a:hover::after {
  width: 100%;          /* no hover, a linha aparece */
}
✨ O efeito de sublinhado animado nos links do Pearl Jam usa ::after + width: 0 → width: 100% com transition. Um truque clássico e elegante do CSS!
05 — Custom Properties

Variáveis CSS

Variáveis CSS (Custom Properties) permitem guardar valores reutilizáveis. Defina uma vez no :root e use em qualquer lugar com var().

🎸 No Pearl Jam

O style.css do site Pearl Jam começa com um bloco :root { } definindo toda a paleta de cores: desde o fundo escuro --brown-dark: #1a0f07 até o dourado --amber-bright: #e8963a. Isso é um sistema de design em CSS puro.

style.css — variáveis reais do site Pearl Jam
/* :root = o elemento raiz (html) — variáveis ficam aqui */
:root {
  /* ── Paleta de cores ── */
  --brown-dark: #1a0f07;  /* fundo mais escuro */
  --brown-deep: #2c1a0e;  /* fundo intermediário */
  --brown-warm: #8b4513;  /* tom marrom quente */
  --amber-bright: #e8963a; /* dourado principal */
  --cream: #f0e4c8;        /* texto claro */
  --text-body: #d4c4a0;    /* texto geral */
}

/* Usando as variáveis → fácil de manter e mudar! */
body {
  background: var(--brown-dark);
  color: var(--text-body);
}

.nav-logo {
  color: var(--amber-bright);
}
🔁
Reutilização
Defina --amber-bright: #e8963a uma vez e use em dezenas de lugares. Para mudar a cor do site inteiro, basta alterar um único valor.
📖
Legibilidade
color: var(--amber-bright) é muito mais legível que color: #e8963a. O nome da variável documenta a intenção, não só o valor.
🎭
Temas
Com variáveis é fácil criar modo escuro/claro. Basta redefinir as variáveis em :root.dark { } e alternar com JavaScript.
🧩
Herança
Variáveis definidas em :root ficam disponíveis para todos os elementos. Você também pode sobrescrever em escopos menores, como .dark-card { --bg: #000; }.
06 — Box Model

O Box Model

Todo elemento HTML é uma caixa. O Box Model define as quatro camadas dessa caixa: content, padding, border e margin.

margin
border
padding
content
Camada O que é Exemplo do Pearl Jam
content O conteúdo em si (texto, imagem) O texto "PEARL JAM" no hero
padding Espaço interno entre conteúdo e borda padding: 1rem 3rem no nav
border A borda do elemento border-bottom: 1px solid rgba(200,114,42,0.2) no nav
margin Espaço externo entre elementos margin-bottom: 1rem no .footer-brand-name
style.css — box model no nav do Pearl Jam
/* Reset global — remove margens e paddings padrão */
*,
*::before,
*::after {
  box-sizing: border-box; /* border e padding ficam DENTRO da largura */
  margin: 0;
  padding: 0;
}

nav {
  padding: 1rem 3rem;          /* padding: vertical horizontal */
  border-bottom: 1px solid rgba(200, 114, 42, 0.2);
}

.btn {
  padding: 0.9rem 2rem;
  border: 1px solid var(--brown-amber);
}
⚠️ box-sizing: border-box é fundamental! Por padrão, width: 200px + padding: 20px resultaria em 240px. Com border-box, o elemento fica em 200px. O Pearl Jam aplica isso globalmente com * { box-sizing: border-box }.
07 — Layout

Flexbox e Grid

Os dois sistemas modernos de layout do CSS. O Flexbox organiza itens em uma dimensão (linha ou coluna). O Grid organiza em duas dimensões (linhas e colunas).

Flexbox

display: flex — como o nav do Pearl Jam
Logo
Links
CTA
style.css — Flexbox no nav do Pearl Jam
nav {
  display: flex;                  /* ativa o flexbox */
  align-items: center;           /* alinha verticalmente ao centro */
  justify-content: space-between; /* logo na esq, links na dir */
}

.hero-buttons {
  display: flex;
  gap: 1rem;             /* espaço entre os botões */
  flex-wrap: wrap;     /* quebra linha no mobile */
  justify-content: center;
}

.nav-links {
  display: flex;
  gap: 2.5rem;
  list-style: none;
}

Grid

display: grid — como o grid de álbuns do Pearl Jam
Ten (1991)
Vs. (1993)
Vitalogy (1994)
No Code (1996)
Yield (1998)
Binaural (2000)
style.css — Grid no cards de álbuns do Pearl Jam
.cards-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  /*
    auto-fill → cria quantas colunas couberem
    minmax(260px, 1fr) → mínimo 260px, máximo proporcional
    Resultado: grid responsivo sem media query!
  */
  gap: 1.5rem;
  margin-top: 3rem;
}

.stats-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr); /* sempre 4 colunas iguais */
  gap: 2rem;
}
Flexbox
Quando usar?
Para layouts em uma direção: menus de navegação, listas de botões, alinhamento de itens lado a lado ou em coluna.
Grid
Quando usar?
Para layouts em duas direções: galerias de cards, layout de página completo, footer com colunas, tabelas visuais.
08 — Responsividade

Media Queries

Media Queries permitem aplicar estilos diferentes dependendo do tamanho da tela. É assim que o site do Pearl Jam funciona bem tanto no computador quanto no celular.

style.css — Media Queries reais do Pearl Jam
/* Estilos padrão: para desktop */
nav {
  padding: 1rem 3rem;
}
.nav-links {
  display: flex;   /* links visíveis no desktop */
}
.hamburger {
  display: none;  /* menu hamburger escondido */
}

/* A partir de 768px de largura (mobile): */
@media (max-width: 768px) {
  nav {
    padding: 1rem 1.5rem; /* menos padding no mobile */
  }
  .nav-links {
    display: none;         /* esconde os links */
  }
  .hamburger {
    display: flex;         /* mostra ☰ hamburger */
  }
  .stats-grid {
    grid-template-columns: repeat(2, 1fr); /* 4 → 2 colunas */
  }
  .footer-top {
    grid-template-columns: 1fr 1fr; /* 4 → 2 colunas */
  }
}
1
Mobile-first vs Desktop-first
O Pearl Jam usa desktop-first: estilos padrão para desktop, com max-width sobrescrevendo para mobile. A abordagem oposta (mobile-first) usa min-width e é atualmente recomendada para projetos novos.
2
Breakpoints comuns
max-width: 480px — celular pequeno
max-width: 768px — tablet / celular grande (Pearl Jam usa este)
max-width: 1024px — tablet landscape / laptop pequeno
3
clamp() — responsivo sem media query
O Pearl Jam usa font-size: clamp(5rem, 15vw, 12rem) no título principal. clamp(mínimo, preferido, máximo) cria tamanhos fluidos que se adaptam à tela automaticamente.
clamp() no Pearl Jam
.hero-title {
  font-size: clamp(5rem, 15vw, 12rem);
  /*
    mínimo: 5rem (celular)
    preferido: 15vw (flui com a tela)
    máximo: 12rem (desktop grande)
  */
}
📖 Glossário

Termos Essenciais

Conceitos fundamentais que você vai encontrar em qualquer projeto CSS profissional.

cascade
A "cascata" do CSS — regras de maior especificidade ou mais abaixo no arquivo prevalecem sobre as anteriores.
specificity
Peso de um seletor. IDs > classes > tags. Determina qual regra vence quando há conflito.
custom property
Variável CSS. Definida com --nome: valor, usada com var(--nome). Essencial para sistemas de design.
box model
As quatro camadas de todo elemento: content, padding, border e margin.
flexbox
Layout unidimensional (linha ou coluna). Ideal para menus, alinhamentos e distribuição de espaço.
grid
Layout bidimensional (linhas e colunas). Ideal para galerias, layouts de página e estruturas complexas.
media query
Regra condicional que aplica estilos apenas em determinado tamanho de tela. Base da responsividade.
pseudo-elemento
Elemento virtual criado via CSS (::before, ::after). Permite adicionar conteúdo sem HTML.
transition
Animação suave entre dois estados CSS. transition: color 0.3s anima a mudança de cor em 300ms.
clamp()
Função CSS que define mínimo, valor fluido e máximo. Cria tamanhos responsivos sem media queries.

Desafio da Aula

🎨 Estilize sua página Pearl Jam

Agora que você tem o HTML criado na Aula 02, crie um arquivo style.css e conecte ao seu index.html. Use tudo que aprendeu hoje:

1
Crie o arquivo style.css e defina variáveis
Comece com um bloco :root { } definindo pelo menos 5 cores do seu tema. Use nomes descritivos como --bg-dark, --accent, --text.
2
Aplique reset e estilos base
Use * { box-sizing: border-box; margin: 0; padding: 0; } e defina body { font-family: ...; background: ...; color: ...; }.
3
Estilize a navegação com Flexbox
Use display: flex; justify-content: space-between; para posicionar logo e links nas extremidades.
4
Crie o grid de álbuns
Use display: grid; grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)); para criar um grid responsivo de álbuns.
5
Adicione uma media query
Use @media (max-width: 768px) para adaptar o layout ao celular: coluna única, menu escondido, paddings menores.
