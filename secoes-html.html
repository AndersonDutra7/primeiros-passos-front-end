Seção 05

Tipografia e
Hierarquia

O conteúdo de uma página é comunicado através de texto. HTML oferece um conjunto de tags que não apenas formata o texto, mas define sua importância, ênfase e estrutura lógica — dando voz e ordem ao que o usuário lê.

<h1> Título Principal </h1>
<h2> Subtítulo </h2>
<h3> Seção </h3>
<h4> ... <h6>
<p> Parágrafo de texto com <strong>ênfase forte</strong> e <em>ênfase sutil</em>. </p>

Tags de Títulos — <h1> a <h6>

O HTML oferece seis níveis de título. O <h1> é o mais importante da página — deve existir apenas um por página e descrever o tema principal. Os demais criam uma hierarquia de subtítulos, como capítulos e seções de um livro.

⚠️ Não pule níveis de heading por questões visuais. Se precisar de um texto menor, use CSS. Pular de <h1> para <h4> prejudica acessibilidade e SEO.
headings — h1 a h6 
<h1>Pearl Jam — Ten Club Tribute</h1>   <!-- título principal da página -->
<h2>Discografia</h2>                     <!-- seção de nível 2 -->
<h3>Álbuns dos anos 90</h3>               <!-- subseção de nível 3 -->
<h4>Ten (1991)</h4>                       <!-- agrupamento menor -->
<h5>Faixas principais</h5>
<h6>Curiosidades</h6>

Parágrafos e Texto Inline

O <p> cria blocos de texto (elementos de bloco). Já <strong>, <em> e <span> são elementos inline — funcionam dentro de um parágrafo sem quebrá-lo, adicionando ênfase ou marcação semântica.

📋 Tag
→<p> — parágrafo de texto
→<strong> — importância semântica (negrito)
→<em> — ênfase sutil (itálico)
→<span> — marcação sem semântica própria
→<br> — quebra de linha
→<hr> — linha divisória temática
✅ Exemplo real
<p>
  O álbum <strong>Ten</strong> foi lançado
  em <em>27 de agosto de 1991</em>
  e é considerado um dos maiores
  discos do grunge.
  Vendeu mais de
  <span class="destaque">
    13 milhões de cópias
  </span>
  nos Estados Unidos.
</p>

Listas: <ul>, <ol> e <li>

Listas organizam itens relacionados. A diferença fundamental: <ul> é para itens sem ordem específica (como ingredientes), enquanto <ol> é para itens com ordem importa (como passos de instalação). Todo item de lista usa <li>.

ul, ol e li 
<!-- Lista não ordenada: membros da banda -->
<ul>
  <li>Eddie Vedder — vocal</li>
  <li>Mike McCready — guitarra</li>
  <li>Stone Gossard — guitarra</li>
  <li>Jeff Ament — baixo</li>
</ul>

<!-- Lista ordenada: passo a passo -->
<ol>
  <li>Clone o repositório</li>
  <li>Crie o arquivo index.html</li>
  <li>Publique no GitHub Pages</li>
</ol>
🗂️ Regra de ouro

Use <strong> quando o conteúdo tiver importância semântica real (como um alerta ou nome de produto). Use CSS font-weight: bold quando for apenas estilo visual. O mesmo vale para <em> vs CSS font-style: italic.

<span> é o "canivete suíço" inline — sem semântica própria, serve apenas para aplicar classes CSS ou selecionar partes do texto com JavaScript.

Seção 06

Links e
Navegação

A tag <a> (âncora) é o que torna a web uma teia de conexões. Com ela conectamos páginas, seções, arquivos e endereços externos — criando a navegação que o usuário percorre ao explorar um site.

Link Externo
<a href="https://pearljam.com" target="_blank" rel="noopener">Site oficial</a>
Âncora Interna
<a href="#discografia">Ir para Discografia</a>
Link de E-mail
<a href="mailto:contato@exemplo.com">Enviar e-mail</a>

A tag <a> e seus atributos

O elemento âncora tem um atributo essencial — o href (Hypertext REFerence) — que define o destino do link. Mas existem outros atributos que controlam o comportamento da navegação e a segurança do link.

Atributo Valor(es) comuns Função
href "https://...", "#id", "pagina.html" Define o destino do link — obrigatório para navegação funcionar
target "_blank", "_self" _blank abre em nova aba; _self abre na mesma aba (padrão)
rel "noopener", "noreferrer" Segurança: evita que a nova aba acesse a janela original via JavaScript
download "arquivo.pdf" Força o download do arquivo ao invés de abri-lo
title "Descrição do link" Tooltip exibido ao passar o mouse; útil para acessibilidade

Tipos de links

01
Link Externo
Aponta para outra URL na internet. Sempre use target="_blank" com rel="noopener noreferrer" por segurança — sem isso, a nova aba pode manipular a página original.
link externo 
<a
  href="https://pearljam.com"
  target="_blank"
  rel="noopener noreferrer"
>
  Site oficial do Pearl Jam
</a>
02
Âncora Interna
O href com #id leva o usuário para uma seção específica da mesma página — útil em menus de navegação como o do nosso projeto Pearl Jam.
âncora interna 
<!-- Link no menu -->
<a href="#discografia">Discografia</a>

<!-- Seção de destino (mais abaixo na página) -->
<section id="discografia">
  <h2>Discografia</h2>
</section>
03
Links Especiais
O href aceita protocolos especiais: mailto: para abrir o cliente de e-mail, tel: para discagem no celular, e caminhos relativos para arquivos locais do projeto.
links especiais 
<!-- Abre cliente de e-mail -->
<a href="mailto:contato@pearljam.com">Enviar e-mail</a>

<!-- Discagem direta no celular -->
<a href="tel:+5548999990000">Ligar agora</a>

<!-- Download de arquivo -->
<a href="setlist.pdf" download>Baixar Setlist</a>
💡 Um link com href="#" não leva a lugar nenhum — rola a página para o topo. Para links sem destino definido ainda, prefira href="javascript:void(0)" ou use um <button> com CSS, que é semanticamente mais correto para ações.
Seção 07

Imagens e
Mídia

Imagens, vídeos e áudios enriquecem o conteúdo visual de uma página. Mas além de inserir mídia, o HTML exige atenção à acessibilidade — garantindo que todos os usuários, incluindo os que usam leitores de tela, tenham uma experiência completa.

🖼️
<img src="show.jpg" alt="Show do Pearl Jam" />
🎬<video controls>
<source src="show.mp4" type="video/mp4">

A tag <img> e o atributo alt

A tag <img> é um elemento vazio (sem tag de fechamento separada). O atributo src define o caminho da imagem e o alt fornece uma descrição textual — obrigatória para leitores de tela e exibida quando a imagem falha ao carregar.

🚫 Nunca omita o atributo alt. Para imagens decorativas sem significado semântico, use alt="" (string vazia) — isso instrui o leitor de tela a ignorá-la. Mas para imagens de conteúdo, sempre descreva o que está sendo exibido.
img — atributos essenciais 
<!-- Imagem com alt descritivo (conteúdo) -->
<img
  src="eddie-vedder.jpg"
  alt="Eddie Vedder durante show do Pearl Jam em Seattle, 1992"
  width="800"
  height="600"
  loading="lazy"
/>

<!-- Imagem decorativa (alt vazio) -->
<img src="textura-fundo.png" alt="" />

<figure> e <figcaption>

Quando uma imagem precisa de legenda, o HTML semântico recomenda envolver tudo em <figure> e usar <figcaption> para a legenda. Isso cria uma relação explícita entre imagem e texto, compreendida por buscadores e leitores de tela.

figure e figcaption 
<figure>
  <img
    src="ten-album.jpg"
    alt="Capa do álbum Ten do Pearl Jam"
  />
  <figcaption>
    Ten (1991) — álbum de estreia que vendeu mais de 13 milhões de cópias.
  </figcaption>
</figure>

Vídeo e Áudio Nativos

O HTML5 trouxe suporte nativo a <video> e <audio> sem precisar de plugins externos. O atributo controls exibe os controles padrão do navegador; autoplay inicia automaticamente (use com cuidado); e múltiplos <source> garantem compatibilidade entre navegadores.

🎬 Vídeo
<video
  controls
  width="100%"
  poster="capa-video.jpg"
>
  <source
    src="show.mp4"
    type="video/mp4"
  />
  <source
    src="show.webm"
    type="video/webm"
  />
  Seu navegador não suporta vídeo.
</video>
🎵 Áudio
<audio controls>
  <source
    src="even-flow.mp3"
    type="audio/mpeg"
  />
  <source
    src="even-flow.ogg"
    type="audio/ogg"
  />
  Seu navegador não suporta áudio.
</audio>
📌 O atributo loading="lazy" em imagens adia o carregamento até que a imagem se aproxime da viewport — melhora significativamente o desempenho em páginas com muitas imagens. Sempre informe width e height para evitar layout shift durante o carregamento.
Seção 08

Gráficos
Vetoriais — SVG

SVG (Scalable Vector Graphics) é uma linguagem de marcação para descrever gráficos vetoriais diretamente no HTML. Diferente de imagens rasterizadas (JPG, PNG), gráficos SVG nunca perdem qualidade ao ser ampliados — são matematicamente perfeitos em qualquer resolução.

Por que usar SVG?

Ícones, logotipos, ilustrações e gráficos em SVG têm tamanho de arquivo reduzido, podem ser estilizados com CSS, animados com JavaScript e são acessíveis por leitores de tela. São a escolha certa para qualquer elemento gráfico que precise ser responsivo.

📐
Escalável
Define formas com coordenadas matemáticas. Amplie para qualquer tamanho sem perda de qualidade — ideal para telas retina e 4K.
🎨
Estilizável com CSS
Atributos como fill, stroke e opacity podem ser sobrescritos por CSS, permitindo temas dinâmicos como dark/light mode.
⚡
Leve e performático
Um ícone SVG simples pode ter menos de 1KB. PNG equivalente pode ter 20KB. Em páginas com muitos ícones, a diferença é significativa.
♿
Acessível
Com <title> e aria-label dentro do SVG, leitores de tela conseguem interpretar e anunciar o conteúdo gráfico.

Tags e atributos essenciais

01
<svg> — o contêiner
Todo SVG começa aqui. O viewBox define o sistema de coordenadas interno; width e height definem o tamanho no layout. Definir apenas viewBox e controlar o tamanho via CSS é a abordagem mais responsiva.
svg container 
<svg
  viewBox="0 0 100 100"
  xmlns="http://www.w3.org/2000/svg"
  width="200"
  height="200"
>
  <!-- formas aqui -->
</svg>
02
Formas básicas: <circle>, <rect>, <line>
As formas primitivas do SVG. Coordenadas referem-se ao sistema interno do viewBox.
circle, rect, line 
<!-- Círculo: cx, cy = centro; r = raio -->
<circle cx="50" cy="50" r="40" fill="#e44d26" />

<!-- Retângulo: x, y = canto superior-esquerdo -->
<rect x="10" y="10" width="80" height="80" rx="8" fill="none" stroke="#38bdf8" stroke-width="2" />

<!-- Linha: coordenadas de início e fim -->
<line x1="0" y1="0" x2="100" y2="100" stroke="#facc15" stroke-width="2" />
03
<polygon> e <path>
<polygon> conecta uma lista de pontos formando um polígono fechado. <path> é o mais poderoso — permite desenhar qualquer forma com comandos como M (mover), L (linha), C (curva bezier) e Z (fechar).
polygon e path 
<!-- Triângulo com polygon -->
<polygon
  points="50,10 90,90 10,90"
  fill="rgba(228,77,38,0.3)"
  stroke="#e44d26"
  stroke-width="2"
/>

<!-- Curva com path -->
<!-- M = move to | Q = quadratic bezier | Z = close -->
<path
  d="M 10,50 Q 50,10 90,50 Z"
  fill="none"
  stroke="#38bdf8"
  stroke-width="2"
/>
🎯 SVG inline vs arquivo externo

SVG pode ser usado de duas formas: inline (colado diretamente no HTML, dentro de <svg></svg>) ou como arquivo externo via <img src="icone.svg">.

SVG inline permite controle total via CSS e JavaScript — ideal para ícones interativos e animações. SVG externo via <img> é mais simples, mas perde a capacidade de ser estilizado dinamicamente.

Seção 09

Tabelas de
Dados

Tabelas HTML são para dados tabulares — informações que fazem sentido em linhas e colunas, como planilhas. Não foram feitas para layout visual. Usadas corretamente, tornam dados complexos legíveis e acessíveis.

Álbum Ano Cópias
Ten199113M
Vs.19937M
Vitalogy19946M

Anatomia de uma tabela HTML

Uma tabela bem estruturada usa elementos semânticos para separar cabeçalho, corpo e rodapé. Isso melhora a acessibilidade e permite que navegadores e leitores de tela interpretem corretamente a relação entre dados e seus rótulos.

01
<table> — o contêiner
Envolve toda a tabela. Internamente, organiza-se em <thead>, <tbody> e opcionalmente <tfoot>. Essa separação é semântica — o visual é controlado por CSS.
02
<thead> e <th> — cabeçalhos
<thead> agrupa as linhas de cabeçalho. Dentro dele, <th> (table header) representa uma célula de cabeçalho — semanticamente diferente de <td>. Leitores de tela anunciam o <th> antes de cada célula de dado correspondente.
03
<tbody>, <tr> e <td> — dados
<tbody> agrupa as linhas de dados. Cada linha é um <tr> (table row). Cada célula é um <td> (table data). Para mesclar células, use colspan (colunas) ou rowspan (linhas).
tabela completa — discografia Pearl Jam 
<table>
  <thead>
    <tr>
      <th>Álbum</th>
      <th>Ano</th>
      <th>Produtora</th>
      <th>Cópias vendidas</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Ten</td>
      <td>1991</td>
      <td>Epic Records</td>
      <td>13 milhões</td>
    </tr>
    <tr>
      <td>Vs.</td>
      <td>1993</td>
      <td>Epic Records</td>
      <td>7 milhões</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="3">Total estimado</td>
      <td>85 milhões</td>
    </tr>
  </tfoot>

</table>
🚫 Nunca use tabelas para layout visual. Antes do CSS, era comum usar <table> para organizar colunas e sidebars. Hoje isso é má prática grave: quebra acessibilidade, dificulta responsividade e aumenta a complexidade desnecessariamente. Para layouts, use CSS Flexbox ou Grid.
Seção 10

Formulários e
Interatividade

Formulários são a principal forma de coletar informações do usuário. Login, cadastro, busca, contato, compra — tudo passa por um <form>. Construí-los corretamente envolve semântica, acessibilidade e usabilidade juntos.

Formulário de Contato
<label> Nome </label>
<input type="text" />
<label> Mensagem </label>
<textarea></textarea>
<button type="submit"> Enviar </button>

A estrutura de um <form>

O elemento <form> agrupa todos os campos. Os atributos action (para onde enviar) e method (GET ou POST) definem o comportamento do envio. Sem action, o formulário envia para a própria URL.

form — estrutura base 
<form action="/enviar" method="POST">

  <!-- Label + Input: sempre associados pelo atributo for/id -->
  <label for="nome">Nome completo</label>
  <input
    type="text"
    id="nome"
    name="nome"
    placeholder="Ex: Eddie Vedder"
    required
  />

  <label for="email">E-mail</label>
  <input type="email" id="email" name="email" required />

  <label for="mensagem">Mensagem</label>
  <textarea id="mensagem" name="mensagem" rows="5"></textarea>

  <button type="submit">Enviar mensagem</button>

</form>

Tipos de <input>

O atributo type do input define o comportamento e a validação automática do campo. Usar o tipo correto melhora a experiência no mobile (abre teclado numérico, de e-mail, etc.) e ativa validação nativa do navegador sem JavaScript.

type Uso Comportamento especial
textTexto livrePadrão; sem restrições
emailEndereço de e-mailValida formato automaticamente; abre teclado de e-mail no mobile
passwordSenhaOculta os caracteres digitados
numberNúmeroAbre teclado numérico; aceita min, max, step
checkboxOpção de marcarMúltiplas seleções; retorna "on" quando marcado
radioOpção única em grupoItens com mesmo name formam o grupo
fileUpload de arquivoFiltra tipos com accept=".jpg,.pdf"
dateDataAbre seletor de calendário nativo
hiddenCampo invisívelEnvia dados sem exibir ao usuário; útil para tokens
submitBotão de envioEnvia o formulário ao clicar; prefira <button type="submit">

<select> — Menu de seleção

select e option 
<label for="album">Álbum favorito</label>
<select id="album" name="album">
  <option value="">Selecione um álbum</option>
  <option value="ten">Ten (1991)</option>
  <option value="vs">Vs. (1993)</option>
  <option value="vitalogy" selected>Vitalogy (1994)</option>
</select>
♿ Sempre associe um <label> a cada campo usando for no label e id no input com o mesmo valor. Isso permite que ao clicar no label, o campo receba foco — e é essencial para leitores de tela anunciarem o campo corretamente.
Seção 11

SEO e
Identidade da Página

Como a sua página é vista pelo Google, compartilhada no WhatsApp e reconhecida pelo navegador — tudo isso é configurado dentro do <head> com meta tags. Ignorar essa parte significa ser invisível para buscadores e parecer sem identidade nas redes sociais.

Resultado no Google
Pearl Jam — Ten Club Tribute
andersondutra7.github.io/pearl-jam
Site tributo ao Pearl Jam com discografia completa, letras e história da banda de Seattle fundada em 1990.
Compartilhamento nas redes
Pearl Jam — Ten Club Tribute
Site tributo · andersondutra7.github.io

meta description — A descrição no Google

A meta description é o texto exibido abaixo do título nos resultados de busca. Não é um fator de ranking direto, mas influencia a taxa de clique (CTR). Deve ter entre 150 e 160 caracteres e descrever o conteúdo de forma atraente.

meta description e keywords 
<head>
  <title>Pearl Jam — Ten Club Tribute</title>

  <!-- Descrição exibida nos resultados do Google -->
  <meta
    name="description"
    content="Site tributo ao Pearl Jam com discografia completa, letras e história da banda de Seattle fundada em 1990."
  />

  <!-- Autor da página -->
  <meta name="author" content="Anderson Dutra" />

</head>

Open Graph — Como aparecer nas redes sociais

Quando alguém cola um link no WhatsApp, Instagram ou Twitter, a plataforma busca as OG tags (Open Graph) para montar o card de visualização — imagem, título e descrição. Sem elas, o compartilhamento aparece genérico ou sem imagem.

open graph tags 
<!-- Open Graph: controla como a página aparece ao ser compartilhada -->
<meta property="og:title"       content="Pearl Jam — Ten Club Tribute" />
<meta property="og:description" content="Discografia, letras e história do Pearl Jam." />
<meta property="og:image"       content="https://seusite.com/og-cover.jpg" />
<meta property="og:url"         content="https://seusite.com" />
<meta property="og:type"        content="website" />

<!-- Twitter Card (mesmo conceito, prefixo diferente) -->
<meta name="twitter:card"        content="summary_large_image" />
<meta name="twitter:title"       content="Pearl Jam — Ten Club Tribute" />
<meta name="twitter:description" content="Discografia, letras e história do Pearl Jam." />
<meta name="twitter:image"       content="https://seusite.com/og-cover.jpg" />

Favicon — O ícone da aba

O favicon é o ícone exibido na aba do navegador, nos favoritos e na tela inicial do celular quando o usuário salva o site. Hoje o padrão é fornecer múltiplos formatos para diferentes contextos.

favicon — configuração completa 
<!-- Favicon padrão (ICO — compatibilidade máxima) -->
<link rel="icon" href="favicon.ico" />

<!-- PNG para navegadores modernos -->
<link rel="icon" type="image/png" sizes="32x32"   href="favicon-32.png" />
<link rel="icon" type="image/png" sizes="16x16"   href="favicon-16.png" />

<!-- Ícone para iPhone ao adicionar à tela inicial -->
<link rel="apple-touch-icon" sizes="180x180" href="apple-icon.png" />

<!-- SVG moderno (escalável, suporte crescente) -->
<link rel="icon" type="image/svg+xml" href="favicon.svg" />

<!-- Web App Manifest (PWA: nome, cor, ícone) -->
<link rel="manifest" href="site.webmanifest" />

🎯 Head completo do projeto Pearl Jam

Agora que você conhece todas as meta tags, veja como fica o <head> completo do projeto — com charset, viewport, title, favicon, OG tags e o link do CSS. Esse é o padrão profissional que você vai usar em todos os seus projetos a partir de agora.

head completo — padrão profissional 
<head>
  <!-- 1. Charset e Viewport (sempre primeiro) -->
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />

  <!-- 2. Título da página -->
  <title>Pearl Jam — Ten Club Tribute</title>

  <!-- 3. SEO -->
  <meta name="description" content="Discografia, letras e história do Pearl Jam." />
  <meta name="author" content="Anderson Dutra" />

  <!-- 4. Open Graph -->
  <meta property="og:title"       content="Pearl Jam — Ten Club Tribute" />
  <meta property="og:description" content="Discografia, letras e história do Pearl Jam." />
  <meta property="og:image"       content="https://seusite.com/og-cover.jpg" />
  <meta property="og:type"        content="website" />

  <!-- 5. Favicon -->
  <link rel="icon"             href="favicon.ico" />
  <link rel="apple-touch-icon" href="apple-icon.png" />

  <!-- 6. Fontes e CSS -->
  <link rel="stylesheet" href="style.css" />
  <script src="script.js" defer></script>

</head>
🧠 Resumindo

O <head> é a identidade invisível da sua página. Ninguém vê diretamente, mas ele controla como o Google te encontra, como o WhatsApp exibe seu link, qual ícone aparece na aba e como o site se comporta no celular.

Trate o <head> com o mesmo cuidado que trata o conteúdo visível — ele é a diferença entre um site amador e um projeto profissional.
